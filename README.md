# Гидро — сайт автомойки

Одностраничный сайт для автомойки **GIDRO** в Санкт-Петербурге.

- Адрес: Заставская ул., 46, корп. 4
- Телефон: +7 (921) 098-00-20
- Режим работы: круглосуточно
- Рейтинг: 5,0 на Яндекс Картах (960 оценок, 509 отзывов)

## Как посмотреть

Откройте `index.html` двойным кликом — сайт работает без сборки и сервера.

Для локального сервера (чтобы карта и шрифты загружались корректно):

```bash
npx serve .
```

или

```bash
python -m http.server 8000
```

## Структура

```
index.html              — главная страница
privacy.html            — политика обработки персональных данных
assets/css/style.css    — все стили
assets/js/main.js       — меню, анимации, галерея, форма записи
assets/img/             — фотографии с карточки Яндекс Карт
assets/favicon.svg      — иконка сайта
```

## Что можно быстро изменить

| Что | Где |
|---|---|
| Телефон | `index.html`, `privacy.html` — поиск `+79210980020` и `+7 (921) 098-00-20` |
| Цены и состав программ | `index.html`, секция `#services` |
| Услуги в форме записи | `index.html`, `select#service`, и кнопки `data-book` |
| Адрес, часы работы, маршрут | `index.html`, секция `#contacts` |
| Отзывы | `index.html`, секция `#reviews` |
| Фотографии | заменить файлы в `assets/img/` с теми же именами |
| Цвета и шрифты | `:root` в начале `assets/css/style.css` |

## Форма записи

Форма работает **без бэкенда**: она проверяет поля и формирует текст заявки. После нажатия «Записаться» посетитель видит готовую заявку и может:

- позвонить администратору и продиктовать её;
- скопировать текст;
- отправить его в Telegram.

Данные не уходят на сервер — это честно указано в форме и в политике конфиденциальности. Если понадобится автоматическая отправка заявок, форму можно подключить к Telegram Bot API, CRM или почте.

## Публикация

Сайт статический, поэтому подойдёт любой хостинг:

- **GitHub Pages** — загрузите папку в репозиторий и включите Pages.
- **Netlify / Vercel** — перетащите папку проекта в панель управления.
- **Обычный хостинг** — загрузите файлы по FTP в корень сайта.

Внешние ресурсы (Google Fonts, карта Яндекс Карт) требуют доступа в интернет. При недоступности шрифтов сайт использует системные.
